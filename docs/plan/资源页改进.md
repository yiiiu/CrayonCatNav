# 资源页改进（2026-11-01）

用户确认：先做 1–4，再做 5–6。

## 第一批（分支 resources-refresh）
1. 加宽布局：`--container` 1240 → 1400px；资源列表改为自适应网格（每列最小 300px，大屏 3 列）。
2. 标题拆分：`lib/resource/display.ts` `splitName` 把「原名（中文说明）」「原名 — 中文说明」拆开，卡片 / 详情页 h1 / 面包屑只显示原名（只拆含中文的说明）；SEO 标题仍用完整名称。采集提示词要求 name 只写原名。
3. 标签去重：`cardTags` 去掉与分类同名、写法重复（忽略大小写 / 空格 / 连字符）的标签，卡片最多 3 个；按分类筛选时卡片不再显示分类标签。重复标签本身仍建议在后台归为别名。
4. 排序与筛选：URL 参数 `sort`（默认推荐 / new 最新收录 / hot 近 30 天详情浏览）、`price`（free / freemium / paid）、`platform`（details.platforms）；排序、定价在搜索框下方，平台在侧栏。

## 第二批（同分支）
5. 侧栏标签云：`listUsedTags(60, cat)` 按当前分类统计使用次数；`splitTags` 只显示前 12 个，其余放进 `<details>` 「展开更多」（无 JS），选中的标签总在可见区。
6. 真实 Logo：`ResourceLogo`（客户端组件）依次尝试后台图标 iconUrl → GitHub 头像（avatars.githubusercontent.com/{owner}）→ 官网 /favicon.ico，加载失败或宽度 < 8px 换下一个，全失败回退 Mono 首字母色块；水合后补查已失败的图片。用于列表卡片、详情页标题、相关资源。
   - 已知限制：部分站点 favicon 只有 16px 会略糊；想要清晰图标可在后台给资源填 iconUrl。
